# P4 经营诊断与决策支持报告

**项目**：中国数字零售与本地生活经营增长分析
**阶段**：P4 经营诊断与决策支持（P4-A/B/C/D 实施）
**日期**：2026-11-08
**数据**：FreshRetailNet-50K，仅 train 90 天
**状态**：实施完成，等待审查；P4 尚未正式验收

---

## 1. 范围与方法

P4 只复用 P1–P3 已验收结果，不重算已有指标；仅新增 P4-A/B/C/D 的整合、规则、关联计数和报告。

| 模块 | 内容 | 主要输入 |
|---|---|---|
| P4-A | 门店综合经营画像 | P1/P3-B/P3-C/P3-D |
| P4-B | 门店问题诊断规则 | P3-D R1–R8、域、组合 |
| P4-C | 商品与门店联动 | P2 SKU 旗标、P3-C 结构、新建 store×SKU 关联 |
| P4-D | 诊断报告 | P4-A/B/C |

**边界**：不做综合评分、不做门店排名、不做因果推断、不做缺货损失/措施效果；不读取 eval；不修改 P1–P3。

### 3.4 规则库与输出

- 规则库 11 条：适用性、单域、多域、R7/R8 结构提示；
- `p4_b_store_diagnosis.csv`：888 行；
- `p4_b_not_applicable.csv`：10 家 SKU<10，仅基础档案；
- `p4_b_store_pairs.csv`：220 条“至少同时命中”门店-域对记录；
- `p4_b_exact_combinations.csv`、`p4_b_domain_summary.csv`、`p4_b_rulebook.csv`。

**规则执行层次（不改变任何命中结果）**：

1. **B0 / B0X：适用性判断**。`in_risk_sample=True` 进入诊断；否则仅基础档案，不诊断/不比较。
2. **B1 / B2 / B3：按 `domain_count` 互斥分层**。0 域为 B1；1 域为 B2-*（五个单域）；≥2 域为 B3（多标签 + 精确组合）。三者不会同时命中。
3. **S7 / S8：独立结构提示**。R7 覆盖偏窄、R8 结构集中可独立出现，不进入运营风险域数量。

不设单一主标签、不设“优先级评分”；上述层次只说明规则触发顺序，不代表风险高低或严重度。

**边界**：`domain_count` 只作计数，不是严重度评分；不设单一主标签；R7/R8 不进入运营域。

## 7. 已知限制

1. P3-B 四象限为弱拟合探索性分层；P4 同类对比不代表经营能力。
2. P3-C HHI 与 SKU 数 −0.900；结构标记不是质量评价。
3. P3-D 风险标记为 P90 尾部筛查；R6/R7 有并列，`domain_count` 不是严重度。
4. P2 SKU 风险为链级旗标（117/35）；低覆盖 SKU 不能外推到全部门店。
5. 观察期内同店共同出现是 assortment 共现，不是同日销售/同日缺货/同日零销；稀疏，只作描述。
6. 888 主样本、10 家低 SKU、18 城；部分单元格 n<20。
7. 无库存、补货、客流、订单、价格、成本、利润；不能分析缺货原因/损失/措施效果。
8. 城市/商品/门店匿名；不能映射真实业务名称。
9. 观察性数据；不做因果推断。
